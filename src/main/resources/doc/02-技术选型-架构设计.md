## 二、逐层选型说明

### 2.1 前端

| 技术 | 版本 | 角色 | 为什么选它 |
|------|------|------|-----------|
| **React** | 18.3 | 框架 | 生态最大，Ant Design 官方一等公民 |
| **TypeScript** | 5.5 | 语言 | 类型检查防低级错误，写 AI 返回的 JSON 处理很舒爽 |
| **Ant Design** | 5.20 | UI 库 | 表格/表单/布局/暗色模式全内置，一行配置切主题 |
| **Vite** | 5.4 | 构建 | 开发启动 < 1 秒，HMR 极快 |
| **axios** | 1.7 | HTTP | 拦截器统一处理 loading/error |
| **highlight.js** | 11.10 | 代码高亮 | 堆栈展示区需要，轻量且支持 Java 语法 |

**不选**：
- ~~Tailwind CSS~~ → 有 Ant Design 不需要额外 CSS 框架
- ~~Next.js~~ → 纯客户端工具，不需要 SSR
- ~~Zustand/Redux~~ → 状态太简单，React 自带 useState + Context 够用

### 2.2 后端

| 技术 | 版本 | 角色 | 为什么选它 |
|------|------|------|-----------|
| **Spring Boot** | 3.3 | 框架 | Java 后端唯一真神，自动配置省心 |
| **Java** | 17 LTS | 语言 | 你的主力语言，Record/sealed/text block 都好用 |
| **MyBatis-Plus** | 3.5.7 | ORM | 单表 CRUD 不用写一行 SQL，分页插件内置 |
| **MySQL** | 8.0 | 数据库 | 你指定 |
| **HikariCP** | SB 默认 | 连接池 | Spring Boot 自带，零配置，性能天花板 |
| **Knife4j** | 4.5 | API 文档 | Swagger 增强版，调试接口不用 Postman |
| **Lombok** | 1.18 | 代码简化 | @Data @Builder 少写模板代码 |
| **Hutool** | 5.8 | 工具库 | Java 版 lodash，字符串/日期/JSON 一站式 |

**不选**：
- ~~JPA/Hibernate~~ → MyBatis-Plus 更轻，对简单 CRUD 更友好
- ~~Redis~~ → V1 没缓存场景，数据库直连够快
- ~~Spring Cloud~~ → 单机应用上什么微服务

### 2.3 AI 接入层

| 选型 | 说明 |
|------|------|
| **多模型支持** | 设计一个 `AIService` 接口，支持切换 OpenAI / Claude / 本地 Ollama |
| **默认推荐** | Claude API（代码解释能力强）或 DeepSeek（便宜） |
| **Key 管理** | 放在 `application.yml`，通过环境变量覆盖 |
| **超时** | 设置 30s 超时，防止 AI 响应慢卡住用户 |
| **fallback** | API 挂了返回友好提示，不白屏 |

```java
// AIService 接口设计
public interface AIService {
    /**
     * 把堆栈翻译成人话
     * @param stackTrace 原始堆栈文本
     * @return 结构化解释
     */
    Explanation explain(String stackTrace);
}
```

**实现策略**：

```
application.yml
  → ai.provider=openai | claude | ollama
  → ai.api-key=xxx
  → ai.model=gpt-4o | claude-sonnet-4-20250514
  → ai.base-url=https://api.openai.com/v1

启动时根据 provider 自动装配对应的 AIService 实现类
```

### 4.1 统一响应封装

```java
@Data
@NoArgsConstructor

public class Result<T> {
    private int code;
    private String message;
    private T data;

    public static <T> Result<T> ok(T data) {
        return new Result<>(200, "success", data);
    }

    public static <T> Result<T> fail(String message) {
        return new Result<>(500, message, null);
    }
}
```

### 4.2 核心 Controller

```java

    private final ErrorExplainService explainService;

    @PostMapping("/explain")
    public Result<ExplainResponse> explain(@RequestBody ExplainRequest req) {
```

### 4.3 AI 调用 Service

```java
@Service
public class ErrorExplainService {

    private final AIService aiService;
    private final ErrorHistoryMapper historyMapper;
    private final ObjectMapper objectMapper;

    public ExplainResponse explain(String stackTrace) {
        // 1. 调用 AI
        String aiRawResponse = aiService.explain(stackTrace);

        // 2. 解析 AI 返回的 JSON
        Explanation explanation = objectMapper.readValue(aiRawResponse, Explanation.class);

        // 3. 识别异常类型（简单正则匹配）
        String errorType = extractErrorType(stackTrace);

        // 4. 存入历史
        ErrorHistory history = new ErrorHistory();
        history.setErrorType(errorType);
        history.setStackTrace(stackTrace);
        history.setExplanation(objectMapper.writeValueAsString(explanation));
        history.setSummary(explanation.getOverview());
        historyMapper.insert(history);

        // 5. 返回
        return ExplainResponse.builder()
                .id(history.getId())
                .errorType(errorType)
                .summary(explanation.getOverview())
                .explanation(explanation)
                .createdAt(history.getCreatedAt())
                .build();
    }

    private String extractErrorType(String stackTrace) {
        // 匹配 java.lang.XXXException 或 XXXException
        Pattern pattern = Pattern.compile("([\\w.]+Exception|([\\w.]+Error))");
        Matcher matcher = pattern.matcher(stackTrace);
        if (matcher.find()) {
            String full = matcher.group(1);
            return full.substring(full.lastIndexOf('.') + 1); // 只要类名
        }
        return "Unknown";
    }
}
```

### 4.4 前端核心组件（简化版）

```typescript
// services/api.ts
import axios from 'axios';

const api = axios.create({ baseURL: '/api' });

export interface ExplainRequest {
  stackTrace: string;
}

export interface Explanation {
  overview: string;
  location: string;
  rootCause: string;
  fixSteps: string[];
  prevention: string;
}

export interface ExplainResponse {
  id: number;
  errorType: string;
  summary: string;
  explanation: Explanation;
  createdAt: string;
}

export const explain = (req: ExplainRequest) =>
  api.post<{ data: ExplainResponse }>('/explain', req);
```

```tsx
// pages/Home.tsx (核心交互)
const Home = () => {
  const [input, setInput] = useState('');
  const [loading, setLoading] = useState(false);
  const [result, setResult] = useState<ExplainResponse | null>(null);

  const handleExplain = async () => {
    if (!input.trim()) return;
    setLoading(true);
    try {
      const res = await explain({ stackTrace: input });
      setResult(res.data.data);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div style={{ padding: 24 }}>
      <Input.TextArea
        rows={10}
        placeholder="📥 粘贴 Java 异常堆栈到这里..."
        value={input}
        onChange={e => setInput(e.target.value)}
      />
      <Button type="primary" loading={loading} onClick={handleExplain}>
        翻译成人话
      </Button>

      {result && (
        <Card title={`🌍 ${result.summary}`}>
          <p><strong>📍 位置：</strong>{result.explanation.location}</p>
          <p><strong>🎯 根因：</strong>{result.explanation.rootCause}</p>
          <p><strong>🔧 修复：</strong></p>
          <ol>
            {result.explanation.fixSteps.map((s, i) => <li key={i}>{s}</li>)}
          </ol>
          <p><strong>💡 预防：</strong>{result.explanation.prevention}</p>
        </Card>
      )}
    </div>
  );
};
```
